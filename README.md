# Smart Campus Student Resource Management System

## Project Overview

The Smart Campus Student Resource Management System is a C++ console-based application developed for NTC CC105 Data Structure.

The system manages student records and campus resources using arrays, dynamic memory, searching algorithms, and matrix processing.

## Project Features

- Student record management
- Student insertion
- Student searching
- Student updating
- Student deletion
- Campus resource management
- Dynamic memory allocation
- Linear search
- 2D matrix processing
- Row and column analysis

## Data Structures

The project uses the following data structures:

- Static array for student records
- Dynamically allocated array for campus resources
- 2D array for matrix processing
